## Proyecto principal

### Funkcionario.com

**Funkcionario.com** es una aplicación web en producción para consultar publicaciones oficiales relacionadas con personal interino docente y no docente en la Comunitat Valenciana.

🔗 **Web:** https://funkcionario.com

El proyecto integra:

- Monitorización de fuentes oficiales.
- Detección de nuevas publicaciones.
- Procesamiento de documentos y PDFs.
- Extracción y estructuración de datos.
- API de consulta.
- Buscadores y filtros para usuarios.
- Consulta de plazas ofertadas docentes.
- Consulta de adjudicaciones por persona.
- Consulta de puestos de difícil cobertura.
- Buscador de centros educativos.
- Información para personal no docente de atención educativa.
- Avisos públicos de novedades.
- Notificaciones mediante navegador y canal público de Telegram.
- Despliegue en servidor propio.

El objetivo del proyecto es facilitar la consulta de información pública dispersa, sin sustituir a las fuentes oficiales.
